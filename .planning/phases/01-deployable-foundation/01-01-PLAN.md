<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer/CI environment to configuration | Environment values configure database access, public backend URL, and monitoring. |
| Browser to Reflex backend | An untrusted browser reaches the rendered page, event endpoint, and health endpoint. |
| Application to PostgreSQL | The app uses a secret connection string to store the readiness probe. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Information disclosure | environment configuration and health route | high | mitigate | Validate secret presence, keep `.env` ignored, use `.env.example` only, and return no credentials or stack traces from `/healthz`. |
| T-01-02 | Tampering | Reflex probe event | medium | mitigate | Accept no client-supplied persistence payload; construct the probe server-side and test only the expected response. |
| T-01-03 | Denial of service | health route database check | medium | mitigate | Perform one bounded query and return an unavailable response on dependency failure without retry loops. |
| T-01-SC | Tampering | Python package installs | high | mitigate | Install only the package-legitimacy-audited dependencies in `01-RESEARCH.md`, lock them with uv, and audit them in Plan 01-02. |
</threat_model>
