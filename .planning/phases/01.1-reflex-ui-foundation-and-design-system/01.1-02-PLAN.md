<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to component gallery | A public browser renders component examples and any feedback semantics. |
| Demo content to portfolio visitor | Synthetic examples can be mistaken for real customers or product claims if not clearly labelled. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01.1-04 | Spoofing | synthetic gallery records | medium | mitigate | Label every example as sample data and use non-identifying, non-customer language throughout the gallery. |
| T-01.1-05 | Information disclosure | form and feedback primitives | medium | mitigate | Ensure gallery examples use no real account, booking, invoice, or environment values and expose no diagnostic payloads. |
| T-01.1-06 | Denial of service | loading controls | low | accept | Gallery controls are presentation examples with no network-triggering workflow beyond the existing safe application runtime. |
| T-01.1-SC | Tampering | Python package installation | high | mitigate | Reuse installed Reflex/Radix components and add no unaudited package. |
</threat_model>
