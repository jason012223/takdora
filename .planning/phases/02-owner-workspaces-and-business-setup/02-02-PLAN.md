<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authenticated browser to owner dashboard | Client-provided route and event data attempts to select a workspace. |
| Owner identity to tenant repository | Server code authorizes the active owner before any private record query. |
| Render cron service to database | A scheduled process applies irreversible deletion to due records. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05 | Elevation of privilege | workspace selection | high | mitigate | Resolve Business only through server-authenticated owner membership and ignore client business IDs for authorization. |
| T-02-06 | Information disclosure | dashboard loaders | high | mitigate | Filter every read by authorized business, return non-enumerating absence responses, and test two-owner attacks. |
| T-02-07 | Tampering | deletion event | high | mitigate | Require the creating owner, explicit dialog confirmation, transactional state transition, and idempotent due-date purge. |
| T-02-08 | Denial of service | scheduled purge | low | accept | The bounded daily job deletes only due inactive workspace roots and can rerun safely after interruption. |
| T-02-SC | Tampering | dependency installation | high | mitigate | Reuse the locked project environment and add no package dependency. |
</threat_model>
