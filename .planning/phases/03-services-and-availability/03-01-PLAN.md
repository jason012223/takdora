## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to catalog events | Untrusted form values and identifiers request changes to business-owned service records. |
| Owner session to business catalog | Authentication becomes authorization only through Phase 2 tenant guards. |
| Service data to later public pages | Customer-facing projections must not expose inactive or private information. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | service create/edit/deactivate commands | high | mitigate | Validate all fields server-side and derive the business from the authenticated owner before each read or write. |
| T-03-02 | Information disclosure | service lookup and display projection | high | mitigate | Tenant-scope private queries and project only active, customer-safe fields for future public use. |
| T-03-03 | Repudiation | catalog lifecycle | medium | mitigate | Retain service identity, state, and timestamps rather than deleting referenced records. |
| T-03-SC | Tampering | dependency installation | high | mitigate | Reuse locked Reflex, SQLModel, and standard-library decimal handling; add no package. |
</threat_model>
