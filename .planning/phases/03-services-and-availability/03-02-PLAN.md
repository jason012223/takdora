| Boundary | Description |
|----------|-------------|
| Browser calendar/form events to schedule state | Untrusted local times, identifiers, and drag payloads request availability-policy changes. |
| Business zone to recurrent policy | IANA zone data defines how weekday and time-of-day policy is interpreted. |
| Schedule policy to publication gate | Private configuration determines whether a public page can be published. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Tampering | schedule and rule events | high | mitigate | Resolve owner/business server-side, validate identifiers and candidate schedules atomically, and persist only valid local-time policy. |
| T-03-05 | Denial of service | drag/drop event transport | medium | mitigate | Keep payloads bounded to an existing block and target interval, deduplicate a drag completion, and retain server-side validation. |
| T-03-06 | Elevation of privilege | publish-hours adapter | high | mitigate | Route readiness through tenant-scoped availability functions rather than browser state or direct table access. |
| T-03-07 | Information disclosure | closure and schedule display | medium | mitigate | Render only the current owner's schedule and omit closure reasons and other private context. |
| T-03-SC | Tampering | dependency installation | high | mitigate | Use the locked Reflex/Radix stack and local browser capabilities; no package is installed. |
</threat_model>
