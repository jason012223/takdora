<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Anonymous browser to public resolver | A path slug and dynamic page inputs request public business data. |
| Browser zone and date selection to availability adapter | Display preferences are untrusted and must not alter booking authority. |
| Owner publication action to public exposure | A private workspace becomes customer-discoverable only after server verification. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Information disclosure | public slug resolver | high | mitigate | Resolve only active published workspaces and return a reduced public projection; old slug handling produces a redirect destination only. |
| T-04-02 | Tampering | publication command | high | mitigate | Derive the workspace from the authenticated owner and reevaluate all publish prerequisites before setting publication state. |
| T-04-03 | Tampering | visitor zone and selected service events | medium | mitigate | Validate zone identifiers, resolve service/business server-side, and use UTC slot identities emitted by the availability engine. |
| T-04-04 | Denial of service | public range loading | medium | mitigate | Bound requested dates to the persisted booking horizon and fetch only the adjacent business-local days needed for the visible visitor date. |
| T-04-SC | Tampering | dependency installation | high | mitigate | Reuse locked Reflex, SQLModel, Python ZoneInfo, and browser Intl APIs; no package is installed. |
</threat_model>
