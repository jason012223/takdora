<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Owner event to issue/void/download command | Invoice identifiers and mutation requests arrive from a private but untrusted browser. |
| Invoice issue transaction to document bytes | Financial snapshots become a durable numbered record and binary document. |
| PDF response to owner browser | Private customer and business information leaves storage only after authorization. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-04 | Tampering | number allocation and issue command | high | mitigate | Lock the business sequence in the issue transaction, enforce the unique number constraint, and make repeat issue return the original result. |
| T-06-05 | Repudiation | issued invoice history | high | mitigate | Snapshot all render inputs and prohibit modification/replacement; preserve number/document on void and make correction a new draft. |
| T-06-06 | Information disclosure | PDF download | critical | mitigate | Filter the invoice by owner-derived business before returning bytes and provide no public URL or object-storage credential. |
| T-06-07 | Spoofing | BIR presentation | high | mitigate | Render an explicit non-compliance notice and avoid BIR registration, e-invoicing, sales-reporting, or certification language. |
| T-06-SC | Tampering | ReportLab installation | high | mitigate | Install only the VERIFIED ReportLab range recorded in `06-RESEARCH.md`, lock it with uv, and run pip-audit through existing quality tooling. |
</threat_model>
