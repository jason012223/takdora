## Trust Boundaries

| Boundary | Description |
|---|---|
| release operator -> staging scripts | Environment names and staging URLs must not select production resources. |
| browser runner -> Compose services | Test traffic crosses a network boundary and creates synthetic records. |
| maintenance switch -> public Nginx | A deployment setting changes public availability. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-07-12 | R | release and recovery | medium | mitigate | Require recorded backup/restore evidence and deterministic script output before promotion. |
